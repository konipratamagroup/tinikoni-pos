Pengaturan & Integrasi Google Sheets

Masukkan URL Web App hasil deploy Google Apps Script Anda untuk sinkronisasi otomatis.

Cara Menghubungkan Google Sheets:

  1. Buka Google Sheets baru Anda.
  2. Klik menu Ekstensi > Apps Script.
  3. Hapus semua kode, lalu pastekan kode Apps Script berikut:
  1. Klik Deploy > New Deployment.
  2. Pilih jenis Web App. Akses (Who has access) ubah ke Anyone (Siapa Saja).
  3. Copy URL Web App dan tempelkan pada kolom di atas.
